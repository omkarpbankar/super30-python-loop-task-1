# Python For-Loop Fundamentals

This assignment builds fundamentals in iteration using `for`, `range()`, strings, lists, tuples, sets, and dictionaries.

## Contents

The notebook covers:

- Printing numbers from 1 to 100, including even and odd numbers
- Generating a multiplication table from 1 to 20
- Calculating a range sum and factorial with loops
- Filtering numbers divisible by 3
- Printing language names with their lengths
- Iterating through a student dictionary
- Counting vowels in a user-provided string
- Reversing a string with a `for` loop
- Finding the largest list value without `max()`

## Run the submission

Open [for_loop_fundamentals.ipynb](Python_for_Loop_Fundamentals/for_loop_fundamentals.ipynb) in VS Code or Jupyter and run the cells from top to bottom. The input exercises prompt for values; pressing Enter uses the included example where a fallback is provided.

No external Python packages are required.
